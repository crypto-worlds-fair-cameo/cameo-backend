# 캔버스 실시간 테스트

```sh
npm run test:realtime
```

Node.js 24와 PostgreSQL 서버 도구(`initdb`, `pg_ctl`, `pg_config`)가 필요하다. 도구 위치는 `pg_config --bindir`로 찾으며 다른 설치를 사용할 때는 `PG_TEST_BINDIR`를 지정한다.

테스트는 `/tmp`에 임시 PostgreSQL 클러스터를 만들고 저장소의 SQL 마이그레이션을 적용한다. 로컬 Unix socket만 열며 운영 DB나 `.env`의 DB 연결은 사용하지 않는다. 테스트 종료 시 클러스터와 임시 파일을 제거한다.

테스트 파일은 순차 실행해 여러 PostgreSQL 클러스터의 동시 자원 점유를 제한한다. 실제 커밋 후 호출 결과만 유실되는 경우, 확인용 DB 조회도 실패하는 경우와 지연 복구 후 종료 연결의 인증 캐시도 검증한다.

실제 NestJS·Socket.IO 서버와 PostgreSQL로 시작·종료 세션 인증, 중간 전송의 인증 캐시, 좌표 방송, 재전송, DB와 최신 대기열을 합친 복구, 서버 재시작 뒤 저장된 그림 복구, 기존 연결 동작을 검증한다. 브러시의 시각적 재현은 프론트에서 같은 렌더러를 사용해 별도로 확인한다.

획 사용 기록과 좌표 묶음 스키마는 사용·완료 시각, 사용자·캔버스 참조, 전역 순서와 묶음 중복 방지, 마이그레이션 재실행을 검증한다. 실제 append의 최초 사용·완료 기록, 중단 후 차감 유지, 동시 탭의 1획 제한, 잘못된 입력·용량 초과 시 미차감, DB 커밋 실패 시 미공개, 마지막 ACK 전 전체 좌표 저장, 정상 종료 flush, 타이머 flush 뒤 재시작 복구, DB prefix와 최신 tail을 합친 고정 head 페이지를 검증한다.
