# GET /api/auth/me — 현재 사용자 조회

현재 세션의 사용자와 만료 시각을 조회한다. [공통 규칙](../app.md)을 따른다.

## 요청

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| 세션 쿠키 | 예 | 로그인 API에서 받은 쿠키. |
| `Origin` 헤더 | 아니오 | 별도 필수 검증 없음. 브라우저 요청에는 CORS 적용. |
| 경로 / 쿼리 / 본문 | 아니오 | 정의된 입력 없음. 본문·쿼리는 무시. |

새 지갑 서명은 필요하지 않다.

## 응답

HTTP 200. 필드 정의는 [로그인 응답](login.md#응답)과 같다.

```json
{
  "statusCode": 200,
  "success": true,
  "data": {
    "user": {
      "id": "95416ea1-fcf7-4e88-a58d-3e2e88543bc8",
      "displayName": "사용자-a7f29c41",
      "avatarUrl": null,
      "wallets": [
        { "chainNamespace": "solana", "address": "6xtn9dTbszpUkeqsgaU4oQwSXBPFkGUHdQTaG2Zeoc8L" }
      ]
    },
    "session": {
      "expiresAt": "2026-10-09T03:00:10.000Z",
      "absoluteExpiresAt": "2026-10-31T03:00:10.000Z"
    }
  }
}
```

- 성공한 조회는 미접속 만료를 조회 시점부터 7일로 연장한다. 최초 발급 후 30일의 절대 만료는 넘지 않는다.
- 같은 세션 토큰의 쿠키를 남은 수명으로 갱신한다. 챌린지 연결 쿠키는 변경하지 않는다.

## 오류

| 상태 | 코드 | 조건 / 메시지 | 쿠키 |
| --- | --- | --- | --- |
| 401 | `AUTH_SESSION_INVALID` | 세션 쿠키 없음·잘못된 형식·중복, 세션 없음·폐기·만료. `로그인이 필요합니다.` | 세션 쿠키 삭제 |
| 403 | `AUTH_USER_UNAVAILABLE` | 유효한 세션의 계정이 정지·탈퇴 상태. `이 계정으로 로그인할 수 없습니다.` | 세션 쿠키 삭제 |

그 외 오류는 [공통 오류](../app.md#공통-규칙)를 따른다. 네트워크 오류·5xx만으로 미로그인을 확정하지 말고 다시 조회한다. 로그인·로그아웃과 조회 요청은 순서대로 처리한다.
