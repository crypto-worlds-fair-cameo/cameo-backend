# POST /api/auth/logout — 로그아웃

요청에 제출한 세션을 폐기하고 인증 쿠키를 삭제한다. 유효한 로그인 세션은 필수가 아니다. [공통 규칙](../app.md)을 따른다.

## 요청

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| `Origin` 헤더 | 예 | 허용된 프론트 출처. |
| 세션 쿠키 | 아니오 | 제출한 세션만 폐기. |
| 경로 / 쿼리 / 본문 | 아니오 | 정의된 입력 없음. 본문·쿼리는 무시. |

본문과 `Content-Type`은 생략할 수 있다.

## 응답

HTTP 200. `loggedOut`은 항상 boolean `true`다.

```json
{
  "statusCode": 200,
  "success": true,
  "data": { "loggedOut": true }
}
```

- 세션 쿠키가 없거나 잘못된 형식·중복·미존재·만료·폐기 상태여도 성공한다.
- 성공 시 세션 쿠키와 챌린지 연결 쿠키를 모두 `Max-Age=0`으로 삭제한다. 다른 세션은 유지한다.
- 같은 세션으로 반복 요청해도 성공한다. 새 로그인 이후 재시도하면 새로 제출한 세션이 로그아웃된다.

## 오류

| 상태 | 코드 | 조건 / 메시지 |
| --- | --- | --- |
| 403 | `AUTH_ORIGIN_NOT_ALLOWED` | 출처 누락·비허용. `허용되지 않은 요청 출처입니다.` 쿠키 변경 없음. |

그 외 오류는 [공통 오류](../app.md#공통-규칙)를 따른다.
